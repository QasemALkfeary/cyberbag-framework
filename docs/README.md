# CyberBag Documentation

CyberBag documentation is organized for maintainers, operators, detection engineers, and researchers.

| Area | Path | Purpose |
|---|---|---|
| Architecture | `docs/architecture/` | System design, component boundaries, and validation plane concepts. |
| Diagrams | `docs/diagrams/` | Mermaid diagram source files. |
| Detection Science | `docs/detection-science/` | Measurement model, scoring concepts, TTD, AHP, and confidence. |
| Setup | `docs/setup/` | Installation and quick-start workflows. |
| Research | `docs/research/` | Related work and research positioning. |
| Screenshots | `docs/screenshots/` | Placeholder location for real dashboard captures. |
| Chapters | `docs/chapters/` | Existing thesis-style project documentation. |
| Foundation | `docs/foundation/` | Existing identity and positioning material. |

## Documentation Principles

- Prefer evidence-backed claims over broad assertions.
- Clearly separate implemented behavior from planned work.
- Keep diagrams source-controlled and reviewable.
- Make scoring assumptions explicit.
- Treat Windows telemetry requirements as operational prerequisites, not implementation details.
