# Changelog

All notable changes to CyberBag should be documented in this file.

This project has not yet published a formal stable release. Until then, entries describe repository-level milestones.

## Unreleased

### Added

- Professional root `README.md` describing CyberBag's architecture, validation workflow, telemetry model, scoring approach, and research positioning.
- Documentation structure under `docs/architecture`, `docs/diagrams`, `docs/detection-science`, `docs/research`, `docs/screenshots`, and `docs/setup`.
- Mermaid diagram sources for high-level architecture, detection pipeline, telemetry flow, scenario execution, scoring workflow, and validation lifecycle.
- Detection Science documentation covering coverage, fidelity, timeliness, actionability, weighted geometric mean, AHP weighting, confidence modeling, and Time-to-Detect.
- Related Work documentation comparing CyberBag with MITRE Caldera, Atomic Red Team, BAS platforms, VECTR, and purple team methodologies.
- Installation and quick-start documentation for backend and Windows agent workflows.
- Community files: `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `ROADMAP.md`, and `CHANGELOG.md`.
