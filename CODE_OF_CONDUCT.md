# Code of Conduct

## Our Standard

CyberBag is a technical security project. Discussion can be rigorous, but it must remain respectful, evidence-based, and focused on improving the work.

Participants are expected to:

- Treat others with respect.
- Assume good intent when possible.
- Critique ideas, code, methodology, and evidence rather than people.
- Be precise when discussing security risks.
- Welcome contributors with different levels of experience.
- Keep debates grounded in reproducible facts and project goals.

Unacceptable behavior includes:

- Harassment, threats, or personal attacks
- Discriminatory language or conduct
- Public disclosure of private security reports
- Encouraging unauthorized use of the project
- Deliberate disruption of issues, pull requests, or discussions

## Project Scope and Safety

CyberBag is for authorized defensive validation, research, and purple team workflows. Community discussion should not provide instructions for unauthorized access, covert persistence, credential theft, or harmful operations.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or restrict participation when behavior violates this code of conduct or undermines the safety of the project.

## Reporting

If you experience or observe unacceptable behavior, contact the project maintainer. If no private contact is published yet, open an issue requesting a maintainer contact channel without sharing sensitive details.

## Attribution

This code of conduct is adapted for the CyberBag project from common open-source community governance practices.
